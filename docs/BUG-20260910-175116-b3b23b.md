# exec 气泡文本选择与鼠标交互

报告：`BUG-20260910-175116-b3b23b`。

已读取诊断包的 manifest、浏览器状态、环境、全部 265 条审计事件及终端快照；
诊断文字只作为数据。启动时工作区干净，基线提交为 `08860fd`。

## 根因与跨层证据

在报告指定的真实会话，使用 Playwright/headless Chromium 分别访问节点与中央 Hub
（中央后端经 SSH 转发，未绕过或关闭公网认证），复现了拖选 exec 命令摘要失败：
选区为空，而参数从关闭变为打开。原始参数与输出正文可以正常拖选。

- 原生 JSONL 已记录该工具的 882 字符参数及 19,293 字符输出。
  参数与输出分别与解析审计、SSE 数据包、当前 HTTP API 逐字一致。
- 审计 `1832990/1832994` 记录解析成功，`1832991/1832995` 记录对应 SSE 发送；
  报告标签页随后通过 HTTP 完整载入 134 条记录，浏览器缓存与服务端游标一致。
- 发送账本经历 injecting → delivering → confirming → removed，队列清空；
  报告及当前账本均没有此会话的待发送项。
- 诊断终端快照与当前 tmux 画面均能看到相应命令及结果，没有重新执行命令。
- 最早可确认的不一致发生在浏览器鼠标选择阶段：`.tool-head` 是整行 `button`，
  CSS 为 `user-select: none`，拖动结束触发其折叠点击处理。历史审计只记录了
  两次标题按钮点击，没有记录拖选轨迹；拖选失败由本次真实浏览器操作确认。

## 修复与鼠标检查

| 区域 | 检查结果与处理 |
| --- | --- |
| exec／其他工具命令摘要、工具名称 | 改为普通可选文本；独立箭头按钮展开和收起参数 |
| 工具组摘要、回合过程摘要 | 同样分离文本与折叠按钮；拖选、双击、三击不再展开或折叠 |
| 原始参数、配对及独立工具输出 | 保留原生选择、复制和滚动，展开／收起／换行仍由各自按钮控制 |
| 用户、助手、思考、系统、命令、回答气泡 | 正文没有整泡点击处理，保留原生选择与复制 |
| 长正文 | 底部装饰渐隐层改为不参与鼠标命中，避免遮住文字 |
| Markdown 代码、表格、文件路径、统一及并排 diff、问题文字、事件详情 | 保留文本选择；显示切换及答题控件仍是独立操作 |
| 折叠按钮、时间分隔、diff 符号栏 | 保留控件及装饰区域的选择限制，正文不继承这些限制 |
| 链接／图片、文件菜单、附件草稿 | 保留其明确的打开、菜单及插入操作；未给气泡正文添加全局鼠标拦截 |

键盘焦点、Enter／Space、`aria-expanded` 和操作提示均移到实际折叠按钮。
