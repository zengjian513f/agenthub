# BUG-20260910-194344-c37385：紧凑会话顶部

用户希望顶部更紧凑，只保留模式切换，其余操作收进“…”菜单。

## 复现与定位

- 完整读取报告 manifest、浏览器状态、环境、151 条审计事件和终端快照，
  查看用户附件。报告浏览器宽度 375px；软键盘弹出时高度降至约 406px。
- 改码前用 Playwright/headless Chromium 打开报告中的精确会话，分别访问独立节点
  和经 SSH 转发的真实中央服务，检查 DOM、对话模式和已存在终端。
  中央顶部高 64.8125px，含五个操作按钮及单独一行机器标签；独立节点为 45px。
- 原生 JSONL 的完成事件、当前 tmux 空闲输入框与附件中的完成摘要对应。
  HTTP 返回 291 条解析记录，消息总数为 289；浏览器将过程合并成 26 个消息块。
  原生文件、HTTP、SSE 与浏览器缓存末尾均为 7,814,166 字节，发送账本与 outbox 为空。
- 审计 `1847108` 的首次 DOM 快照已处于加载完成、空闲且数据对齐的状态。
  后续切换终端正常。首个与本次期望不符的环节是详情头的渲染布局：
  `head()` 直接展开全部操作，手机样式又保留了单独的机器信息行。
  报告时浏览器已切回对话，附件记录的是此前终端画面，两种模式均复现相同顶部。

## 修改

- 顶部改为单行标题、对话/终端切换和“…”入口；手机保留返回。
  收藏、过程展开/折叠、报告问题、搜索匹配跳转和停止/删除/隐藏父会话均放入菜单。
- 会话消息数、机器、时间、模型、目录和标识仍可在菜单中查看。
  菜单文字随收藏、过程和会话状态更新；新建会话采用相同布局。
- 菜单支持方向键、Home/End、Escape、Tab 离开及外部点击关闭。
  保持原有子代理切换和常驻控制台可用性说明，菜单可越过终端区域，窄屏可滚动。

  模式切换正常，菜单各操作行通过实际点击命中检查，无 JavaScript 错误。
- 扩展隔离菜单浏览器测试，覆盖中央与独立节点、亮暗主题、320–1698px 宽度、
  375×406 键盘场景、长标题、终端三种布局、子代理、新建会话、动态收藏文字、
  过程切换、报告弹窗、删除取消、搜索匹配跳转与键盘操作。
- 配套更新控制台、父会话和原有大套件的菜单访问路径；模拟节点收藏接口返回真实契约字段。
