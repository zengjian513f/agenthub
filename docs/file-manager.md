# Web 文件管理器

从聊天气泡中的目录链接进入 `files.html`，所属机器由会话确定。采用单窗口布局：
顶部导航和地址栏、文件操作工具栏、文件列表或图标网格、底部项目统计和任务入口。
没有左侧导航、搜索、多标签页、收藏夹、机器切换或文件回收站界面。
导航操作按钮只显示图标，保留悬停说明和无障碍标签；新建、上传文件使用纯文字按钮。

## 浏览与选择

- 单击选中，双击目录进入，双击文件预览；工具栏或右键菜单下载。
- Ctrl/Cmd 多选、Shift 连选、空白区域拖动框选，复选框适合触屏。
- Ctrl/Cmd+A 选择当前页；方向键移动选择；Enter 打开；Escape 取消选择。
- F2 重命名、Delete 永久删除（需确认）、Ctrl/Cmd+C/X/V 复制／剪切／粘贴，F4 编辑路径。
- 后退、前进、上级目录、面包屑、可编辑绝对路径、刷新均保留会话机器上下文。
- 详细信息、大图标、小图标三种视图；按名称、类型、大小、修改时间排序。
  目录始终优先；隐藏文件开关、排序和视图偏好保存在浏览器。
- 每页 500 项；分页作用于完整排序结果，不截断目录。全选和框选作用于当前页。

## 文件操作

支持新建空文件／文件夹、重命名、复制、剪切、粘贴、拖放移动、批量永久删除、
多文件上传、普通文件下载以及文件夹／多文件 ZIP 打包下载。
拖动时按 Ctrl 为复制，默认移动；拖到文件夹上会以该文件夹为目标。
从浏览器电脑拖入文件会上传。本期不提供本地目录上传和跨机器复制。

删除按钮、右键菜单和 Delete 快捷键均打开永久删除确认框，列出目标路径；确认后
直接删除文件或整棵目录，不新增回收站副本，无法从页面撤销。取消确认不会提交任务。
符号链接仅删除链接自身，不删除链接指向的内容。

同名项目可停止并提示、保留两份、跳过或覆盖。目录覆盖是替换整个目录，不合并目录树。
本次调整仅改变主动删除行为：覆盖及跨文件系统移动原有的服务器端安全备份机制不变，
这些备份可能需要额外空间。旧回收站数据不自动清空，历史还原／清理 API 保留兼容，
但不再提供回收站界面或历史回收站任务的重试按钮。会话回收站不受影响。

复制、移动、压缩、解压、删除和还原运行于节点后台任务。任务显示已处理项目和字节数，
支持取消、失败重试；已经完成的项目不重复执行，源文件变化时要求重新选择。
任务串行修改文件系统，避免两个页面上的文件任务互相覆盖。
发布使用临时文件和原子无覆盖重命名；复制失败不会发布残缺的目标。
已完成的单个项目不会因随后取消整个批次而自动撤销，尤其已删除的内容无法恢复。

上传每块最多 8 MiB，支持中断后继续。刷新或关闭页面会中断浏览器上传，服务端保留
已经接收的分块；在任务中选择原文件可继续（名称、大小、修改时间必须一致）。
全部分块到达后，由后台任务发布到目标目录。文件任务与传输记录保存在节点的
`~/.local/share/agenthub/file-manager/`，服务重启后的未完成文件任务标记为中断，
由操作者选择重试。临时上传、打包下载产物和任务记录当前不自动过期。
普通文件下载的进度和取消由浏览器下载管理器提供；目录和多文件下载先在任务面板完成打包。

## 预览与压缩

- 图片可预览；大图标视图中图片和视频缩略图由节点 `ffmpeg` 生成，限制并发和超时。
  没有 `ffmpeg` 或无法解码时显示普通图标。
- 浏览器支持的音视频、PDF 使用内嵌预览，支持 HTTP Range 分段读取及拖动播放位置。
  浏览器不支持的编码仍可下载。
- 文本、代码、HTML、SVG 以文本预览；最多显示前 1 MiB，代码使用现有高亮模块。
  不执行文件中的脚本。属性弹窗显示路径、类型、大小、修改时间、权限及 UID/GID。
- 压缩／解压目前支持 ZIP。解压到独立目录，拒绝路径穿越、符号链接、特殊文件和
  重复条目；限制条目数，并检查可用磁盘空间。ZIP 打包遇到符号链接会报告错误，
  普通文件复制则保留符号链接自身。

## 接口与权限

`GET /api/session/files` 支持目录列表、`info`、`preview`、`thumbnail`、`jobs`、
`trash`、`artifact` 模式；`POST /api/session/files/action` 提交或控制任务；
`POST /api/session/files/upload` 接收上传分块。Hub 按会话路由 JSON、二进制及 Range，
文件操作执行在所属节点，中央不操作同名的本地文件。

每次请求检查会话及所选子会话有效性。首次进入核对该视图确实引用过入口目录，
将此入口记录在节点私有状态中，使入口重命名或删除后仍可导航和查看任务。允许导航到父目录
及其他节点账号可访问的路径；它不是限制在起始目录内的文件分享服务。

写操作仅在节点启用 `--terminal` 时开放，沿用现有登录及节点访问保护，拒绝跨站来源，
操作请求必须为 JSON，上传必须为二进制。不会提升系统权限，不执行 shell，禁止修改
文件系统根目录、用户主目录本身或文件管理器私有数据目录。

## 验证

单元测试：`python3 -m unittest discover -s tests -p 'test_file*.py'`。
免费浏览器测试：`python3 tests/file_manager_e2e.py`、`python3 tests/file_links_e2e.py`。
这些测试使用隔离会话与临时文件，覆盖节点和挂载路径下的 Hub，不启动任何付费 CLI。
PDF 原生浏览器查看器回归测试：`python3 tests/file_pdf_e2e.py`，需要完整 Chromium
（`python3 -m playwright install chromium`）或已安装的 Chrome，不能仅安装 headless shell。
