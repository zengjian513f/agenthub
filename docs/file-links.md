# 回复中的链接与文件操作

## 显示规则

标准 Markdown 链接 `[说明](目标)` 只显示可点击的“说明”，不显示路径和语法括号。
`[说明](<output/report.pdf> "标题")` 同样只显示说明。目标独立保存在链接元数据中，
右键菜单根据实际目标类型提供操作；本地目标检查失败时保留说明文字，不生成可点击链接。

普通文字中的 `说明 (output/report.pdf)` 不属于 Markdown 链接，仍只给括号内已有路径
增加点击能力。普通文字不增删字符，不把相对路径替换成绝对路径；绝对路径用于悬浮提示
和“复制完整路径”等操作。不要混淆 Markdown 源码、标准渲染和 CLI 特有的路径展示。

行内代码中的完整路径、文件名或 HTTP/HTTPS URL 也参与链接化，无需额外加括号；
保留原有代码样式，不把代码片段中的命令、字符串或版本号拆成链接。
代码块不参与链接化。文件名或 URL 自带的括号属于目标的一部分。
缺失、歧义、无法确认的文件引用保持可读的普通文本。

## 目标类型与动作

| 目标 | 网页点击 | 右键动作 |
| --- | --- | --- |
| 节点文件 | 经会话授权的文件接口查看；不能安全内联的内容作为文本或附件 | 复制完整路径、复制所在目录路径（不含文件名）、下载 |
| 节点目录 | 在新标签页打开文件浏览器，支持子目录、上级目录与面包屑导航 | 复制完整路径；禁用下载 |
| HTTP / HTTPS | 浏览器打开原始目标 URL | 复制链接地址、在新标签页打开；不提供文件或目录操作 |
| `file:` | 不自动链接 | 浏览器电脑上的路径不能通过节点的文件存在性检查来确认 |
| 其他协议 | 不自动链接 | 后续按协议逐一支持，不将未知协议作为路径或 HTTP 处理 |

下载是保存文件到浏览器电脑，不等于调用本地应用打开文件。
当前内联文件读取仍有 32 MiB 上限，显式下载采用流式传输。
目录不会隐式打包下载。文件浏览器显示隐藏文件，目录优先排序，每页 500 项，
可翻页查看全部条目；单击选择、双击预览，通过工具栏或右键菜单流式下载。
支持中文、空格及特殊字符文件名，
浏览器前进、后退与刷新会保留当前目录。

## 文件浏览器的访问范围

`files.html` 是独立文件管理页面，沿用中央站和节点现有访问保护。入口须携带有效的
会话、所选子会话和其中已出现的目录引用；每次请求检查会话，首次进入验证目录引用。
通过验证的入口保存于节点私有状态，允许在入口目录重命名或删除后继续导航和还原。
`/api/session/files` 在入口校验后接受绝对 `path` 导航，可访问上级目录直到文件系统根目录，
也可跟随符号链接，访问范围受节点服务账号的操作系统权限限制。这是登录操作者的
节点文件浏览功能，不是将访问范围锁定在起始目录的文件分享链接。
Hub 按会话路由到所属节点；中央不会读取同名的中央本机路径。开启写权限的节点还提供
上传、文件操作及回收站，详见[文件管理器](file-manager.md)。
特殊设备、管道及失效符号链接不可下载。原 `/api/session/file` 保持只读取会话引用的语义，
用于文件预览和旧标签页兼容。
滚动部署时，根据节点解析响应中的 `file_browser` 能力启用新页面；尚未升级的节点
继续使用原有目录文本列表。

## 后端与前端边界

后端只解析在选定会话中出现过的引用，结合该会话工作目录、已记录的完整路径
和实际文件系统确定目标。短文件名也检查会话中明确提及的目录的直接子项，
以支持工作目录未改变时引用新克隆目录中的文件；不递归搜索磁盘，不猜测同名文件。
工作目录与已提及目录中存在多个同名目标时，保持不可点击，需使用完整路径。
批量解析接口返回 `ref`、`path`、`kind`（`file` 或 `directory`）及节点标识。
前端依据确认后的类型提供动作，不通过扩展名推断目录或文件。
旧标签页仍可读取兼容的 `resolved` 字段；未知类型不启用下载。

点击和下载时后端再次校验；解析完成后文件被删除等情况应返回明确错误。
Hub 只路由到所属节点，不能将引用文字当作协议字段改写。

“复制完整路径”复制完整目标；文件的“复制所在目录路径”只复制其所在目录。
目录链接直接复制目录自身，不增加重复的复制选项。
